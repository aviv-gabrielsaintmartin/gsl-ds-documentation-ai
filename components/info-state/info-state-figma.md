## Choosing the illustration

To select the correct illustration, go to the common page in the illustration
library. For example: [Common Hero Illustrations](https://www.figma.com/design/BwvS9ir2UuM4gBHVMhjy0O/1.-Gemini-Symbols-Library?node-id=5688-312).

There you will find illustrations for most use cases — informational purposes,
error messages, and more.

**If the illustration you need is not there, request it** on `#gemini_symbols`.
[Learn more about the symbol library process](https://kugawana.slack.com/archives/C03HLJU6E3U/p1723193835245029).
